# SoftLink Fuel

Under-construction website for SoftLink I.T Solutions (U) Ltd.

Static HTML, CSS and JavaScript with five image slides, company details, phone and WhatsApp contact links.

## Azure Static Web Apps

Connect this repository's `main` branch to an Azure Static Web App using the **Free** hosting plan.

- Build preset: Custom
- App location: `/`
- API location: empty
- Output location: empty

No package installation or application build is required. Publish `index.html` and `assets/` together.

Domain: softlinkfuel.app
